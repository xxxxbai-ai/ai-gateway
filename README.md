本目录是 2026-11-06 整理的交付源码。A 网关实际调用 B 分类、C 路由和 D 模型适配；包含用户要求重新制作的浅色 Qt 客户端。

## 使用与构建

- 统一构建入口：`integration/release/CMakeLists.txt`。
- Windows 构建脚本：`integration/release/build-windows.ps1`。
- A 的交付说明和验证：`docs/A交付说明.md`。
- 新客户端：`client/CMakeLists.txt`、`client/README.md`。根目录旧 Qt 工程作为成员原提交保留。
- 使用 Qt Creator 编译新版客户端时，打开 `client/CMakeLists.txt`；完整网关与客户端一起构建时，使用 `integration/release/CMakeLists.txt`。
- 交付包内按顺序打开“01-启动真实网关.cmd”和“02-打开客户端.cmd”，密钥只在网关窗口填写。

## 已接入及范围

四个平台配置来自 D：DeepSeek、千问、智谱、Kimi。自动模式按五类任务的配置评分选模；这些仍为人工预设，不代表实测能力排名。自动故障切换最多再调用一个不同的备用模型，手动模式不换模型。

网关只监听本机。客户端的历史保存在本机，网关仍按每条问题独立处理。外部用户托管、账号计费、双回答投票和自动学习评分不属于当前已实现功能。

B 的多义词、局部否定、输出语言与翻译话题等误判已按用户授权修正，见 `docs/B分类修正说明.md`。原有 30 条冻结题保持不变，另加 100 条补充题；通过这些样例不代表任意问题都能正确分类。C 的选模算法、能力评分和 D 的模型调用实现保持原样。已有模块报告保留各自当时的验收范围。
