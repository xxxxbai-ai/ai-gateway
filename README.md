# AI 网关问题意图分类器

把用户输入的问题快速分类到 **代码 / 数学计算 / 翻译 / 写作 / 通用** 五类之一，
供网关路由到对应的专业模型。纯 C++ 实现，无第三方依赖。

## 原理

基于规则的 **关键词 + 正则 加权打分**，不调用大模型，做到毫秒级预判：

```
输入问题 → 归一化(ASCII 转小写) → 五类分别打分 → 取最高分类别 → 输出类别+置信度
```

- 每个类别维护一份「关键词/正则 → 权重」字典，命中即累加权重。
- 正则捕捉关键词覆盖不到的结构特征：`1+2*3`、`for(int i...)`、`#include`、`translate ... to`。
- 「通用」类设固定基线分兜底；四类都无命中时通用自然胜出。
- 置信度 = 胜出类别得分 ÷ 五类总分。

## 分类依据

| 类别 | 关键词特征 | 正则/结构特征 |
|------|-----------|--------------|
| 数学计算 | 计算、方程、求解、平方、根号、积分、导数、阶乘、质数、最大公约数、进制、次方、幂… | `1+2`、`3x4`、`x=1`、`sin()`、整句算式 |
| 代码 | 代码、报错、bug、调试、函数、指针、多线程、爬虫、接口、API、python/c++/java/rust… | `#include`、`import`、`def`、`{ } ;`、`for/while/int/class` |
| 翻译 | 翻译、translate、译成、翻成、英文/日语/法语…、什么意思、怎么读、用英语怎么说 | `translate ... to ...` |
| 写作 | 作文、文章、论文、邮件、文案、演讲稿、润色、改写、扩写、总结、大纲、帮我写… | 靠文体名词(作文/邮件)而非动作词区分 |
| 通用 | 什么是、为什么、怎么、如何、介绍、推荐、区别、原理… + 基线分 | 兜底 |

> 关键：**「帮我写」这类中性动作词设低权重，靠后面的宾语名词(代码/函数 vs 文章/邮件)最终定类**，避免「帮我写个函数」被误判为写作。

## 编译

```powershell
g++ -std=c++17 -O2 classifier.cpp -o classifier.exe
```

## 用法

```powershell
classifier.exe "帮我写一封辞职邮件"     # 分类单个问题
classifier.exe --test                    # 跑内置自测(21 用例)
echo 今天天气怎么样 | classifier.exe     # 从标准输入逐行分类(UTF-8)
```
